# 11/9 팀 회의록 (1차 + 2차 통합)

- 대회: 암 아형(26종) 분류 해커톤, 평가 지표 Macro F1 (2026-11-06 ~ 11-13)
- 1차 회의: 11/9 오전 11시 · 데이터 분석·전처리 취합
- 2차 회의: 11/9 오후 3시 · 제출 후보 결정과 팀 통합 방향

---

## 1. 한눈에 보는 결론

1. **교차 검증보다 리더보드가 약 0.1 낮은 원인은 코드 실수가 아니다.** 쌍 규칙 없는 모델은 누가 만들어도 리더보드 0.28~0.30이었다.
2. **쌍 규칙을 적용하면 리더보드가 약 +0.10 오른다** (0.2877 → 0.3914). 단, 운영진 확인 전이다.
3. **팀 최고 점수는 exp10(0.3919)이다.** v2 변수에 로지스틱 회귀 0.8, LightGBM 0.2를 섞고 쌍 규칙을 더한 모델이다.
4. **노이즈 증강(exp12)은 실패했다(0.3698).** 그래서 이 방식의 가상 검증("부푼 검증")을 모델 선택 기준으로 쓰자는 제안은 철회했다.

## 3. 1차 회의 (11시): 데이터 분석·전처리 취합

### 3-1. 팀원 발견

| 작업 | 발견 | 근거 |
|---|---|---|
| 변수 설계 | 쌍 규칙 + v2 변수 | 쌍 규칙만으로 리더보드 +0.10 |
| 모델 탐색 | 희소행렬, 외부 유전자 정보(mygene 염색체 위치), CNN 이미지화 | CNN은 정확도 4% 수준으로 중단 |

### 3-2. EDA 핵심 정리 (Train 기준)

| 발견 | 모델링 연결 |
|---|---|
| 전체 칸의 99.19%가 WT인 희소 데이터 | 희소행렬, 선형 모델 |
| 아형 크기 최대 20.7배 차이 (BRCA 786명, DLBC 38명) | 층화 K-겹, 클래스 가중치 |
| 아형마다 변이 수가 크게 다름 (THYM 2개 ~ SKCM 85.5개) | 로그 변이 수 변수 |
| 변이가 0개인 환자 94명 (THYM·THCA·LAML에 몰림) | 변이 0개 여부 변수 |
| 같은 IDH1도 R132H는 뇌종양 97.7%, R132C는 37% | 핫스팟 변수 |
| 변이 값은 같고 라벨만 다른 환자 (KIPAN·KIRC, GBMLGG·LGG) | 쌍 규칙, 그룹 교차 검증 |

### 3-3. 1차 회의 결론

- 07번 코드와 다른 팀원 코드 모두 쌍 규칙이 없으면 리더보드 0.29~0.30이었다. 차이는 처리 방식이 아니라 **쌍 규칙 유무**였다.
- 일부 전처리와 쌍 규칙은 규정 해석이 애매해서 **운영진 문의가 필요**하다.

## 4. 2차 회의 (3시): 제출 후보와 팀 통합 방향

### 4-1. 회의 중 나온 질문과 답

| 질문 | 답 |
|---|---|
| 큰 아형에 데이터가 쏠려서 작은 아형을 못 맞히는 것 아닌가? | 불균형은 사실이지만 주원인이 아니다. 아형 크기와 F1의 순위 상관이 −0.003이다. 작은 ACC(72명)는 0.87이고, 큰 KIPAN(515명)은 0.22다. 불균형은 `class_weight="balanced"`로 이미 처리 중이고, 추가 보정 효과도 +0.01 이내였다. |
| WT는 어떻게 처리했나? | 처음부터 "변이 없음 = 0"으로 처리했다. 빈칸은 `fillna("WT")`로 채우고, WT가 아닌 칸만 변이로 분석한다. 칸 하나만 보고 판단하며 통계는 쓰지 않는다. |
| "버틴다"는 무슨 뜻인가? | 입력이 망가져도 점수가 덜 떨어진다는 뜻이다(강건성). |

### 4-2. 팀원별 전처리 비교

| 항목 | 변수 설계 담당 (v2) | 모델 탐색 담당 |
|---|---|---|
| 빈칸 처리 | `fillna("WT")` | 소문자 `nan` 문자열이 변이로 잘못 셈 (버그) |
| 변이 표현 | 침묵 변이 제외 여부 + 절단형 여부 + 핫스팟×2 | TF-IDF + 빈도 상위 100개 유전자 |
| 누수 위험 | 낮음 (핫스팟·열 선택을 폴드 안에서) | 2단계 모델을 Train 전체로 학습 |

**결정**: 팀 표준 전처리는 v2로 한다. v2 → exp10이 기반 모델이다.

### 4-3. 쌍둥이 프로필 분석 (Train)

- 변이 프로필이 똑같은 환자는 922명이고, 450개 그룹으로 묶인다.
- KIRC 334명 중 약 81%, LGG 229명 중 약 76%가 반대 코호트에 쌍둥이가 있다.
- 변이가 0개인 94명은 지문이 모두 같지만 15개 아형이 섞여 있다. 그래서 쌍 규칙에서 제외한다.
- BRAF V600E 하나만 가진 18명(THCA 17명, LGG 1명)은 쌍 규칙 대상이 아니다. 모델이 처리한다.
- **쌍 규칙 조건**: 변이가 1개 이상이고, 똑같은 Train 환자의 라벨이 KIPAN·KIRC·GBMLGG·LGG 중 하나뿐일 때만 반대 라벨로 바꾼다.

### 4-4. 쌍 규칙 의존 아형 (5겹 전체)

| 아형 | 모델만 | 쌍 규칙 포함 |
|---|---|---|
| KIRC | 0.19 | 0.76 |
| KIPAN | 0.22 | 0.63 |
| LGG | 0.46 | 0.79 |
| GBMLGG | 0.28 | 0.60 |

신장·뇌 아형은 모델 혼자서는 점수가 낮고, 쌍 규칙이 있어야 점수가 나온다.

### 4-5. 제출 결정과 결과

- 2차 회의 결정에 따라 exp12(노이즈 증강)를 제출했다. 결과는 **0.3698**로 exp10보다 −0.022였다.
- 해석: 노이즈 증강이 리더보드에서는 효과가 없었다. 그래서 이 방식의 "부푼 검증"을 모델 선택 기준으로 쓰자는 제안은 **철회**한다.
